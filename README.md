# The Curse of Khonsu

### Unreal Engine 5 • Solo Development • Action RPG Prototype

A solo-developed action RPG prototype built in Unreal Engine 5, focused on gameplay systems, combat, AI, traversal, animation, and interactive environments.

## Overview

The Curse of Khonsu is a systems-focused action RPG prototype developed independently from the ground up.

The project explores combat, enemy AI, player traversal, progression, environmental interaction, animation-driven gameplay, and cinematic presentation within a single playable experience.

## Key Features

### Combat & Equipment

- Modular combat system supporting melee combos, kicks, shields, armor, bows, arrows, throwable spears, and special abilities.
- Implemented reactive hit responses and physics-based death states across combat encounters.

### Traversal & Locomotion

- Implemented player traversal systems including swimming, horse riding, wall climbing, vaulting, crouching, dodge rolls, assassinations, and fall damage.
- Built contextual animation and audio transitions to synchronize player movement with gameplay states and environments.

### Enemy AI

- Designed multiple enemy archetypes using Behavior Trees, including patrol, investigation, pursuit, and combat behaviors.
- Implemented specialized behaviors for wildlife, suicidal attackers, and mage enemies with AoE and homing attacks.
- Added enemy distraction and friendly-fire mechanics to create more dynamic encounters.

### Gameplay & Progression

- Developed inventory, equipment, and weapon collection systems supporting multiple weapon types and combat loadouts.
- Implemented NPC interactions, quest-giving, XP and level progression, and gameplay-driven progression states.
- Built environmental interactions including destructible containers, randomized item drops, and dynamic gameplay feedback.

## Animation & Systems

### Animation-Driven Gameplay

- Developed animation-driven combat and locomotion using Animation Blueprints and Blend Spaces.
- Implemented contextual animations for combat, traversal, swimming, and environmental interactions.
- Synchronized animation states with gameplay logic, audio, movement, and combat reactions.

## Systems & Technical Architecture

- Built modular Blueprint systems for combat, equipment, AI, traversal, interaction, and progression.
- Implemented reusable gameplay logic designed to support multiple character and enemy types.
- Integrated physics-based interactions, dynamic gameplay states, and contextual feedback across systems.
